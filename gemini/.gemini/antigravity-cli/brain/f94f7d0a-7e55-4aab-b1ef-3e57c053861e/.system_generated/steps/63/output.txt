With Hyprland's transition to a Lua-based configuration system (introduced in version 0.55), window management actions are handled via Lua dispatchers under the `hl.dsp.window.*` namespace[1][2]. 

The equivalent dispatcher functions for fullscreen, closing/killing, and moving windows are structured as follows:

### 1. Fullscreen
* **Dispatcher:** `hl.dsp.window.fullscreen({ mode?, action?, window? })`[1]
* **Parameters:**
  * `mode`: Can be `"fullscreen"` or `"maximized"`[1].
  * `action`: Can be `"toggle"`, `"set"`, or `"unset"` (defaults to `"toggle"`)[1][3].
  * `window`: Optional window selector (defaults to `"activewindow"`)[1][3].
* **Example Usage in a Bind:**
  ```lua
  hl.bind("SUPER + F", hl.dsp.window.fullscreen({ action = "toggle" }))
  ```

### 2. Closing / Killing Active Windows
In the Lua configuration setup, closing and killing windows are split into separate dispatcher options:
* **Graceful Close:** `hl.dsp.window.close({ window? })` — Sends a graceful close request to the window[1][4].
* **Force Kill:** `hl.dsp.window.kill({ window? })` — Forcefully kills the window process[1][5].
* **Example Usage in a Bind:**
  ```lua
  hl.bind("SUPER + Q", hl.dsp.window.close())
  -- or for force killing:
  hl.bind("SUPER + SHIFT + Q", hl.dsp.window.kill())
  ```

### 3. Moving Windows
The legacy `movewindow` commands map to various methods under `hl.dsp.window.move({ ... })` depending on whether you are moving a window in a direction, to a workspace, across monitors, or via coordinates[6]:
* **Directional Move:** `hl.dsp.window.move({ direction = "l"|"r"|"u"|"d" })` (or using variables/layouts)
* **To a Workspace:** `hl.dsp.window.move({ workspace = "name", follow = true })`[7]
* **To a Monitor:** `hl.dsp.window.move({ monitor = "name", follow = true })`[6]
* **Exact Coordinates:** `hl.dsp.window.move({ x = 100, y = 100, relative = false })`[6]
* **Example Usage in a Bind:**
  ```lua
  hl.bind("SUPER + SHIFT + L", hl.dsp.window.move({ direction = "right" }))
  ```

*(Note: To execute these dispatchers inside a custom Lua function rather than directly in a `hl.bind`, you must wrap them with `hl.dispatch()`, e.g., `hl.dispatch(hl.dsp.window.fullscreen({ action = "toggle" }))`)*[8].
