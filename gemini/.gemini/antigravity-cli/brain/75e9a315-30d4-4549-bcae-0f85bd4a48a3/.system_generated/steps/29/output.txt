The search for ""hyprpaper" "wallpaper {" path directory cycle OR slideshow" returned the following summary:
If you are trying to configure a **slideshow**, **directory path cycling**, or **random wallpaper rotation** using `hyprpaper`, there are two main approaches: using **native configuration blocks**[1] or using a **lightweight shell script with IPC (`hyprctl`)**[2][3].

---

### Method 1: Native `hyprpaper.conf` (Directory support)
Recent versions of `hyprpaper` natively accept a **directory path** inside the `wallpaper { ... }` block, along with parameters for rotation timeout and ordering[1]:

1. Open your configuration file at `~/.config/hypr/hyprpaper.conf`[1].
2. Add a `wallpaper` block pointing to your directory[1]:

```ini
splash = false
ipc = true

wallpaper {
    monitor = eDP-1                    # Leave empty (monitor =) for a fallback/all monitors
    path = ~/Pictures/Wallpapers/      # Path to your wallpaper directory
    fit_mode = cover                   # Options: contain | cover | tile | fill
    timeout = 300                      # Time interval in seconds between changes (default is 30)
    order = random                     # Display order (currently supports 'random')
    recursive = false                  # Set to true if you want to scan subfolders
}
```

---

### Method 2: Shell Script + IPC (The Custom Slideshow Approach)
If you want granular control, want to avoid preloading an entire massive directory into RAM all at once[4], or need to sync it with tools like `hyprlock`[5], you can use a short loop script leveraging `hyprctl hyprpaper`[3].

#### 1. Create a script (e.g., `~/.config/hypr/hypr-slide.sh`):
```bash
#!/usr/bin/env bash

# Path to your wallpaper directory
WALLPAPER_DIR="$HOME/Pictures/Wallpapers"
INTERVAL=300 # Time in seconds

while true; do
    # Pick a random image from the directory
    RANDOM_WALL=$(find "$WALLPAPER_DIR" -type f \( -name "*.jpg" -o -name "*.png" -o -name "*.webp" \) | shuf -n 1)

    if [ -n "$RANDOM_WALL" ]; then
        # Unload unused images to save RAM, preload the new one, and apply it via IPC
        hyprctl hyprpaper preload "$RANDOM_WALL"
        hyprctl hyprpaper wallpaper ",$RANDOM_WALL"  # Use monitor name instead of comma if targeting a specific screen
        hyprctl hyprpaper unload unused
    fi

    sleep "$INTERVAL"
done
```

#### 2. Make it executable:
```bash
chmod +x ~/.config/hypr/hypr-slide.sh
```

#### 3. Start it automatically with Hyprland:
Add this line to your `~/.config/hypr/hyprland.conf`[5]:
```ini
exec-once = ~/.config/hypr/hypr-slide.sh
```

*(Note: Ensure that `ipc = true` is set inside your `~/.config/hypr/hyprpaper.conf` file so that runtime `hyprctl` commands can communicate with the daemon[6][7]).*
