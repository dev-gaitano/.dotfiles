Hyprland natively supports **Lua configuration** (introduced in v0.55 to replace the legacy `hyprland.conf` / `hyprlang` syntax)[1][2]. 

### 1. Native Lua Configuration (`hyprland.lua`)
Instead of writing configuration files in `hyprland.conf`, you can use a `hyprland.lua` file inside your `~/.config/hypr/` directory[3][4]. 

* **How it works:** If Hyprland finds a `hyprland.lua` file at startup, it loads it natively[5]. (Previously, community tools like the third-party `hyprlua` plugin[4] handled this, but Lua is now integrated directly into the compositor core).
* **Migration Tool:** If you are transitioning an old configuration, tools like [`hyprlang2lua`](https://github.com/EIonTusk/hyprlang2lua) can automatically convert your old `hyprland.conf` blocks into the modern Lua format[1].

#### Example Syntax:
```lua
-- General configuration and bindings using the native Lua API
hl.config({
    general = {
        gaps_in = 5,
        gaps_out = 10,
        border_size = 2,
    },
})

-- Keybindings
hl.bind("SUPER", "Return", function()
    hl.exec("alacritty")
end)

hl.bind("SUPER", "Q", function()
    hl.killactive()
end)
```

---

### 2. Lua and Hyprland Plugins
With native Lua support, interacting with plugins, writing custom window layouts, and managing hooks has become deeply integrated[6][7]:

* **Loading Plugins via Lua:** You can load external plugins directly via code using `hl.plugin.load(path)`[8] or configure them inside your Lua setup blocks[7].
* **Custom Layouts:** Hyprland's Lua API allows you to write entirely custom window management layouts directly in Lua using `hl.layout.register()` without needing to compile a C++ plugin[6].
* **Advanced Scripting:** You can hook into Lua events, build custom timers, manage notifications, and utilize built-in utility wrappers natively[9][2].
