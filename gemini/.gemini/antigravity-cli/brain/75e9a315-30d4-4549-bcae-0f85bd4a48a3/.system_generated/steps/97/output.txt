The search for ""hyprpaper.conf" "ipc" default on true" returned the following summary:
In your `~/.config/hypr/hyprpaper.conf` file, the global option for enabling Inter-Process Communication (IPC)—which allows you to control `hyprpaper` dynamically via `hyprctl`[1]—is set like this[2]:

```ini
ipc = true
```

### Details:
* **Default Value:** `true`[2]
* **Purpose:** Keeping IPC enabled (`true`) allows you to use commands like `hyprctl hyprpaper` to change wallpapers on the fly, list loaded images, or script dynamic wallpaper switches without restarting the application[3][4].
* **Disabling it:** If you want to disable IPC completely, you can set it to `false`[5]:
  ```ini
  ipc = false
  ```
