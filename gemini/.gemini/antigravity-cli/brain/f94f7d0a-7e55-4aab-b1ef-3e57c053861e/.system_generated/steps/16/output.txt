`/usr/share/hypr/hyprland.lua` is the official default starter configuration file bundled with **Hyprland (version 0.55 and newer)**, which transitioned from the legacy `hyprlang` (`hyprland.conf`) syntax to native **Lua** configuration[1][2].

### Key Purpose & Usage
* **Default Template:** When you start using Hyprland with Lua configuration enabled, this file serves as the official reference template showcasing how to structure monitors, input options, layouts, animations, window rules, and keybinds using the Lua API[2][3].
* **Quick Setup / Migration:** If you want to migrate away from an old configuration format or quickly generate a baseline working environment, you can copy the system-provided template directly into your user config directory[4][5]:
  ```bash
  mkdir -p ~/.config/hypr
  cp /usr/share/hypr/hyprland.lua ~/.config/hypr/hyprland.lua
  ```
* **Location Path:** Depending on your distribution package, it lives alongside helper assets and LSP stubs (such as `hl.meta.lua`) under the shared system path `/usr/share/hypr/`[6][7].
