The search for "site:wiki.hyprland.org "lua" OR site:wiki.hypr.land "lua" OR "hyprland.lua"" returned the following summary:
Starting with **Hyprland version 0.55**, Hyprland officially transitioned away from the custom `hyprlang` syntax (`.conf` files) to a **Lua-based configuration system** (`.lua` files)[1][2][3]. 

If you are looking for documentation, code snippets, or guides regarding the new Lua configuration architecture on the official Hyprland Wiki, key sections include:

* **Configuration File Path:** Typically located at `~/.config/hypr/hyprland.lua` (or `/usr/share/hypr/hyprland.lua` for the default template)[2]. Modular files can be loaded using standard Lua `require()`[2].
* **Lua Code Snippets & Examples:** The wiki provides community and official patterns under [Lua code snippets on the Hyprland Wiki](https://wiki.hypr.land/Extra/Lua_code_snippets/) (covering things like per-layout binds, smart gaps, and custom window management logic)[4].
* **Advanced Configuration & APIs:** For scripting and extending the window manager, the wiki details APIs under [Advanced configuration – Lua events & utilities](https://wiki.hypr.land/Configuring/Advanced_configuration/)[5]. This includes lifecycle events (`config.reloaded`, `window.active`, etc.)[6] and custom Lua-driven layouts (`hl.layout.register`)[7].
* **Older Versions:** If you are still looking for legacy formatting prior to the 0.55 shift, the wiki houses previous guidelines under the 0.54 documentation versions[3].
